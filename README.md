응시자가 AI와 작업하는 순서와 문서 양식을 정리한 개인 준비용 공개 저장소입니다. SK하이닉스·크래프톤·OpenAI의 공식 배포물 또는 승인 자료가 아니며, 실제 시험 문제·자료·정답은 포함하지 않습니다. 하이닉스 1차 예선 자료는 참고하지 않았습니다.

## 핵심 흐름

**구현 전 계획 문서 → 구현과 AI 검증 → 사용자 직접 기능 테스트 → 테스트 결과 반영 → 구현 상세 문서 → 제출 점검**

1. 실제 과제 README와 기존 지침을 읽고 필수 제출물·파일명·제출 위치를 확인합니다.
2. 구현 코드를 작성하기 전에 계획 문서를 만듭니다. 목표·요구사항·구현 방식·작업 순서·검증·시간 배분을 적습니다.
3. 합의된 범위의 핵심 기능을 구현하고 AI가 수행 가능한 검증을 직접 실행합니다.
4. 사용자에게 기능별 테스트 순서와 기대 결과를 안내합니다. 사용자 확인을 기다리는 동안 미확인 기능을 통과로 표시하지 않습니다.
5. 사용자가 테스트 결과를 알려주면 실패·보완 사항을 수정하고 관련 검증을 다시 수행합니다. 수정이 사용자 확인에 영향을 주면 해당 부분의 재확인을 요청합니다.
6. 사용자가 해당 판본·범위의 기능 테스트 완료를 알린 뒤, 실제 코드와 검증 근거를 다시 확인해 구현 상세 문서를 작성합니다.
7. 상세 문서를 읽고 구조·판단 이유·실패 조건을 이해한 뒤 플랫폼에서 제출합니다. 후속 서술형 등 AI 금지 단계에서는 답변·첨삭·설명을 요청하지 않습니다.

필요 문서는 과제가 허용한 실제 작업 위치에 새로 작성합니다. 하네스 폴더 안에 결과물을 작성하거나 여기에 Git Push하지 않습니다. 별도 설치·자동 초기화·전역 설정 변경·실행 스크립트·외부 의존성은 없습니다.

## 역할과 사실 구분

- AI가 직접 수행 가능한 코드·명령 검증은 AI가 합니다. 사용자 테스트로 대신하지 않습니다.
- 화면과 실제 업무 흐름은 사용자가 직접 테스트하고, 본인이 알려준 범위·판본의 결과만 기록합니다.

- 문서 제공은 사용자 이해 완료의 증거가 아닙니다.
- 이 저장소는 작업 지침입니다. 검증·감독·제출을 자동 보장하는 프로그램이 아닙니다.
